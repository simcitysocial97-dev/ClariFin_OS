## 5. Semantic Contract Authority Conflict

The system has **competing semantic authorities** for financial quantities:

### savings_rate
| Authority | Declaration | Evidence |
|-----------|-------------|----------|
| DTO description | "percentage (0-100)" | `Field(description="Savings rate as percentage (0-100)")` |
| Service implementation | Multiplies by 100 | `round(... * 100, 2)` |
| Wire gate logic | Expects ratio (0-1) | `if savings_rate > 1.0: SEMANTIC_VALUE_DRIFT` |
| Zod schema | Max 1 | `z.number().min(0).max(1)` |

**Resolution Required:** Choose canonical representation:
- Option A: Store as ratio (0-1), transform to percentage for display
- Option B: Store as percentage (0-100), update wire gate and Zod

### emi_ratio
Same conflict as savings_rate.
