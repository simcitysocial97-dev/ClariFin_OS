## 3. Infrastructure Diagnosis

### Problem Statement
When running `python -m mutmut` from either repo root or backend directory:
- Configuration loads successfully from `backend/pyproject.toml [tool.mutmut]`
- Mutants are generated correctly
- But **test execution fails silently** — no tests are discovered/run per mutant

### Evidence
```bash
$ python -m mutmut results 2>&1 | grep -c "no tests"
7439
$ python -m mutmut results 2>&1 | grep -c "Killed:"
0
$ python -m mutmut results 2>&1 | grep -c "Survived:"
0
```

### Possible Causes
1. **PYTHONPATH isolation**: mutmut runs tests in isolated temp directories where imports fail
2. **Fixture setup**: Database/fixtures not available in mutation context
3. **Test selection paths**: The `pytest_add_cli_args_test_selection` config may not be respected by this mutmut version (3.7.0)
4. **Working directory mismatch**: Tests resolve paths relative to cwd which differs in mutmut context

### What Works
- Direct pytest execution: ✅ All 339 tests pass
- mutmut mutant generation: ✅ (16,427 mutants generated in prior run)
- mutmut result collection: ✅ (results file populated with "no tests" entries)

### What Fails
- mutmut test execution: ❌ (zero tests run against any mutant)
