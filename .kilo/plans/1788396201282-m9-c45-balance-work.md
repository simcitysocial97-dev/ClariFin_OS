## Implementation Plan (User-Confirmed Priority Order)

### Phase 1: M45.14 — L-ARCH-001 Investigation (FIRST — URGENT)
**Blocks: M45.13 refinement, M45.24 final certification**

#### Task 1.1: Create Python 3.12+ Syntax Probe Tests
Create probe files in `runtime/generated/m9-c45/l-arch-001-probe/`:
- `test_match_statement.py` — PEP 634 pattern matching
- `test_type_params.py` — PEP 695 type parameter syntax
- `test_exception_groups.py` — PEP 654 ExceptionGroup
- `test_walrus_comprehensions.py` — walrus in comprehensions
- `test_union_types.py` — PEP 604 X | Y syntax
- `test_fstring_nested.py` — f-strings with nested quotes

Each file: 2-3 functions using the syntax, plus a simple test that would detect mutation.

#### Task 1.2: Run mutmut on Each Probe
- `python runtime/verify.py mutation --target l_arch_001_probe` (custom scope)
- Record: which syntax features generate mutations vs which are silently skipped
- Document: exact skipped patterns

#### Task 1.3: Quantify Repository Impact
- Grep ClariFin_OS source (`backend/src/`) for Python 3.12+ syntax usage
- Calculate: % of production code using potentially-skipped syntax
- Cross-reference with mutmut-generated mutation counts
- Determine: is mutation score inflated due to silent skips?

#### Task 1.4: Update Artifacts
- Update `mutation-population-completeness.json` with L-ARCH-001 test results
- Update `backend-qualification-decision.json` with quantified risk

**Acceptance**: L-ARCH-001 impact quantified; decision on whether to retain mutmut or evaluate alternatives.
