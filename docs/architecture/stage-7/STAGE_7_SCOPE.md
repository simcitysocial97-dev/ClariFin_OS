# Stage 7 — Simulation & Forecast Engine

## Objective

Enable deterministic financial simulation and forecasting.

The engine must answer:

"What happens if..."

before recommending actions.

Every simulation must be reproducible.

Every forecast must expose assumptions.

---

## Responsibilities

The engine provides:

- Cashflow forecasting
- Net worth projection
- Loan payoff simulation
- Investment growth projection
- Budget scenario simulation
- Emergency fund simulation
- Retirement projection
- Goal achievement prediction
- Monte Carlo-ready architecture (future)
- Scenario comparison

---

## Out of Scope

Machine Learning

LLMs

Natural language

Automation

---

## Exit Criteria

Every scenario produces deterministic outputs.

Every forecast exposes assumptions.

Every projection links back to evidence.

No hidden calculations.
